# 🪄 AdGenie AI — AI-Powered Multi-Platform Ad Creative Generator

AdGenie turns a short product description into platform-optimized image and video ad creatives, automatically tuned to target audience age groups and sized for Instagram, Facebook, and YouTube.

![AdGenie Banner](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **⚡ Fast Campaign Synthesis**: Generate multi-platform ad creatives from a single product description prompt.
- **🎯 Age-Aware Creative Engine**: Tailor tone, pacing, colors, and copy to specific demographics:
  - **Gen Z (16–24)**: Fast cuts, bold saturated colors, short-form native feel.
  - **Millennial (25–40)**: Story-led messaging, clean aspirational visuals.
  - **Gen X (41–56)**: Clear benefits upfront, trust & credibility signals.
  - **Boomer (57+)**: Legible type, straightforward copy, warm tone.
- **📱 Multi-Platform Sizing**: Sized for:
  - **Instagram**: 4:5 Vertical Feed
  - **Facebook**: 4:5 Feed
  - **YouTube**: 16:9 Wide Aspect
- **🖼️ Creative Export**: Download copy variants, headlines, subheadings, and CTAs ready for Ad Manager launch.
- **🎨 Modern ChatGPT-Style Dark Aesthetic**: Built with React, Tailwind CSS, Lucide icons, and HSL glow system.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abhi941331-alt/AdGenie.git
   cd AdGenie
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.
